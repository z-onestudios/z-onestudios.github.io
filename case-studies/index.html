01
Healthcare / Telemedicine

Kashmir Heal

Healthcare in Kashmir had a problem no one was solving elegantly — patients in remote valleys couldn't reliably get appointments, doctors were buried in paper records, and nobody had the full picture. We built the platform that changed that. Not just a booking app. A full medical operating system.

02
Interactive Gaming

Mines

We wanted to see how smooth we could make a web-based probability game. Turns out, pretty damn smooth. The challenge was building a game engine that felt snappy, had satisfying visual feedback, and didn't lag on mid-range phones. We built it in vanilla JS with a custom state machine and Canvas rendering loop.

"We wrote the physics first, then the UI."
The state machine handles 25+ game states cleanly. Multiplier calculations run in a Web Worker so they never block the render thread. Sound synthesis uses the Web Audio API with no external libraries.
03
Sports & Entertainment

Headshot Paintball

Paintball arenas have some of the worst websites you've ever seen. We fixed that. High-energy design, instant booking workflow, and zero friction between "I want to play" and "my slot is confirmed." The whole site loads in under a second — even on a mobile hotspot.

"The brief was: make it feel dangerous."
We did. Heavy typography, fast transitions, red on red-on-black color system, and an arena section that slides in like a tactical map. The booking flow took 4 iterations to nail the right friction level — enough to feel intentional, not enough to lose anyone.
